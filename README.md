# 薪酬设计与激励测算沙盘

一个**自托管、纯前端、MIT 开源**的薪酬设计与测算工具。把「薪酬组件 → 薪酬结构 → 员工覆盖」的专家建模方法做成可点击的积木式工作台，无需后端、无需数据库、无需登录，打开浏览器即可完成薪酬结构设计、批量算薪、成本报表与公平性诊断。

所有数据只保存在本机浏览器中，不会上传到任何服务器，支持一键全量备份与恢复。

---

## 适用场景

- 设计固浮结合的薪酬结构（固定工资、绩效、提成、津贴、社保、个税）
- 多套薪酬方案并行测算与对比（总部、门店、销售等不同结构）
- 月度批量算薪、工资条生成与锁定
- 薪酬成本汇总、固浮比分析、同岗公平性与职级倒挂诊断
- 数据安全敏感，希望数据不出本机、可离线自托管

---

## 核心能力

### 三层灵活模型，逐层覆盖

1. **组件层**：定义「怎么算」。每个组件可自由增删改，支持加项/扣项、税前/税后。
2. **结构层**：决定「算哪些」。用组件按分组组合成多套薪酬结构，可在结构内覆盖组件参数。
3. **员工层**：解决「特殊情况」。员工选择结构，可按生效月份对单个组件做员工覆盖。

覆盖优先级：**员工覆盖 > 结构覆盖 > 组件默认值**。

### 五种计算方式

- 固定金额
- 按比例（基于其他组件）
- 积木公式（全程拖拽选择，不写代码）
- 阶梯分段（如阶梯提成）
- 外部输入驱动（如每月录入的业绩基数）

积木公式底层采用安全 AST 解析、拓扑排序与循环引用检测，杜绝任意代码执行与循环计算。

### 完整数据治理

- 组件、结构、员工均支持完整增删改查
- 软删除进入回收站，可还原或彻底删除
- 工资条确认后锁定为快照，不可直接修改，只能作废重算
- 内置可编辑的个税、社保、公积金参数包，政策调整后自行维护即可
- 三套内置模板：通用服务业、连锁门店、销售型，可一键套用并继续自定义

### 分析与协同

- 报表中心：月度应发/个税/扣除/实发汇总、部门与结构成本、固浮比，支持导出 Excel
- 公平性分析：同岗/同职级薪酬分布、个体偏离标记、职级倒挂检测
- 员工与工资条支持 Excel 导入导出，全量 JSON 备份/恢复

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 类型检查
npm run typecheck

# 妙搭 / 单文件产物构建（输出到 dist）
npm run build

# GitHub Pages 分包构建（输出到 dist/ghpages）
npm run build:gh
```

GitHub Pages 构建会按路由懒加载拆分依赖，图表与 Excel 库仅在进入对应页面时才下载；推送至 `main` 分支后，由 `.github/workflows/deploy-pages.yml` 自动发布。

## 技术栈

- React 19 + TypeScript + Vite（Rolldown）
- React Router（路由懒加载）
- Tailwind CSS + shadcn/ui（Radix UI）
- Recharts（图表）
- SheetJS（Excel 导入导出）
- 双引擎本地存储：localStorage（配置类）+ IndexedDB（工资条等大容量数据）

---

## 数据安全

- 无账号、无网络上报，数据仅写入浏览器 localStorage 与 IndexedDB
- 清理浏览器缓存或更换设备前，请在「参数与设置 → 备份与数据」中下载全量备份
- 恢复备份即按备份内容覆盖对应数据，整个过程离线完成
