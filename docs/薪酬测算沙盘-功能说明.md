# 薪酬测算沙盘 功能说明（本次更新）

## 一、模块定位

新增独立模块「薪酬测算沙盘」（左侧导航「测算沙盘」分组，路由 `/sandbox`）。面向 HR 年底薪酬结构测试、调薪与预算测算，支持调整任一变量、全员成本与结构即时联动，可反复试错，且不写入正式数据。

模块回答三个问题：**要花多少钱、钱怎么分、有没有超预算。**

## 二、新增能力

### 五个调整变量

| 变量 | 形式 | 作用口径 |
|---|---|---|
| 整体调薪幅度 | 相对 % | 参数级作用于固定金额：固定组件金额、绩效/考勤组件的固定基数、工龄各档金额 |
| 绩效系数 | 绝对值 | 统一覆盖所有绩效组件的当月系数；绩效工资 = 固定基数 × 绩效系数 |
| 浮动工资整体系数 | 相对 % | 作用于除固定项、绩效项之外的浮动项（提成、奖金、津贴、全勤奖等） |
| 社保公积金缴费基数 | 策略选择 | 足额 / 按法定下限 / 按工资比例 / 统一基数，通过申报基数实现 |
| 预算上限 | 金额 | 不参与计算，仅作对照线 |

### 对照输入

- 月度营收（可选）：用于计算人力成本率；不填则不显示。

### 可视化

- KPI 卡：总用工成本、人均、固浮比、预算执行、人力成本率，均带「相对基线」差异；
- 固浮比环形图、总用工成本 vs 预算上限对比、按部门/结构分组成本（Tabs 切换）；
- 模拟明细表，点击行下钻查看单人模拟工资条。

## 三、口径说明

- **工资性总用工成本 = 应发 + 企业承担社保公积金**；不含福利费、教育经费、工会经费、补充商业保险等非工资性人力成本。
- 固浮比基于**应发工资**计算，社保不纳入固浮比。
- 社保缴费的法定上下限由参数包维护，企业调整的是申报基数，引擎自动在法定上下限内封顶。
- 年度估算 = 月度 × 12，未含年终奖、年中调薪、社保基数年中调整与人员增减。
- 每个加项只受一个杠杆控制，固定 / 绩效 / 其他浮动互不重复。

## 四、数据边界

- 全部为内存「影子计算」，不调用写入接口，不生成持久化工资条，不修改方案、组件与参数包。
- 切换方案或刷新页面，临时变量重置。

## 六、第二批规划
